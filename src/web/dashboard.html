Create a bot with @BotFather, paste its token, then press Start in the bot. Leave empty and save to keep the current token.

Handlers

Notifications

Notifications are delivered by the control bot.

Security

Encrypts the database, the default session, and anti-delete storage on disk. You will need it at every start (or put FLY_MASTER_PASSWORD in fly-telegram.env).

Desktop device profiles

A profile sets the device name, OS and app version an account reports to Telegram. It stays pinned to the account. Applies after a restart.

Network and updates

Applies to new connections after a restart. Tor mode: every account uses its own circuit, so accounts leave through different exit IPs.
