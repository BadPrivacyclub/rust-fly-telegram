Welcome to fly-telegram

This wizard connects your Telegram account in a few minutes. Everything stays on this computer.

  1. Protect the panel with a password
  2. Optionally connect a control bot
  3. Enter your Telegram API keys
  4. Sign in with your phone number

Panel password

You will use it to open this panel. Without a password you can still sign in with a one-time link printed in the console.

Commands start with this symbol, e.g. .help. Several prefixes can be separated by spaces.

Control bot (optional)

A bot sends you notifications and gives you a control menu inside Telegram.

  1. Open @BotFather and send /newbot
  2. Copy the token it gives you and paste it below
  3. For help with buttons, also send /setinline to BotFather
  4. After setup, press Start in your bot so it can message you

Telegram API keys

  1. Open my.telegram.org/apps and sign in
  2. Create an application (any name)
  3. Copy api_id and api_hash

Leave empty to reuse the saved keys.

Proxy (if Telegram is blocked)

socks5://127.0.0.1:9050 is treated as Tor: every account gets its own circuit.
